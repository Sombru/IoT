# Part 1 — K3s and Vagrant

Two VMs provisioned with Vagrant (VirtualBox provider):

- **anmakaroS** — `192.168.56.110` — K3s server (control-plane)
- **anmakaroSW** — `192.168.56.111` — K3s agent, joined to the server

## Usage

```bash
vagrant up
```

Check the cluster from the server:

```bash
vagrant ssh anmakaroS
sudo kubectl get nodes -o wide
```

Both nodes should show `Ready`.

## Notes

- The join token is generated by `scripts/server.sh` and shared with the
  worker via the synced `/vagrant` folder (no manual copy needed).
- Network interface for K3s is auto-detected by IP, not hardcoded
  (`eth1`/`enp0s8` differ across distros/kernels).
- `vagrant halt` to stop safely, `vagrant status` for status, `vagrant up` to resume.
